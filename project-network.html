Conception et sécurisation d'une infrastructure réseau multi-site avec Cisco Packet Tracer.

Cisco Packet Tracer Networking Security

01

Contexte

Ce projet consiste à concevoir une infrastructure réseau multi-site simulée avec Cisco Packet Tracer.

L'objectif est de mettre en place une architecture permettant aux différents sites de communiquer tout en assurant la segmentation et la sécurité du réseau.

02

Objectifs

  • Concevoir une architecture réseau multi-site.
  • Configurer les équipements Cisco.
  • Mettre en place le routage entre les différents réseaux.
  • Segmenter le réseau avec des VLAN.
  • Mettre en place le DHCP.
  • Sécuriser les communications réseau.

03

Technologies

Cisco Packet Tracer Network simulation
VLAN Network segmentation
Routing Inter-network communication
DHCP IP address management
ACL Network access control

04

Sécurité

La sécurité de l'infrastructure repose notamment sur la segmentation du réseau et le contrôle des communications entre les différents réseaux.

Des mécanismes de filtrage peuvent être utilisés afin de limiter les communications autorisées entre les différentes zones du réseau.

05

Ce que j'ai appris

Ce projet m'a permis de mieux comprendre la conception d'une infrastructure réseau, la segmentation des réseaux et la configuration des équipements Cisco.

Il m'a également permis de mettre en pratique plusieurs notions étudiées dans le cadre de mon Mastère Infrastructure & Réseaux.
