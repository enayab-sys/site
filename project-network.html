Infrastructure réseau
multi-site

Conception et sécurisation d'une infrastructure réseau simulant une entreprise composée d'un siège et d'une agence distante, avec Cisco Packet Tracer.

Cisco Packet Tracer Réseau Sécurité

01

Présentation

Ce projet met en place une infrastructure réseau multi-site simulant une entreprise composée d'un siège (HQ) et d'une agence distante (Branch).

  • Segmentation en VLAN et routage inter-VLAN
  • Routage dynamique OSPF entre les deux sites
  • Agrégation de liens avec EtherChannel LACP
  • Service DHCP pour l'agence
  • Traduction NAT/PAT vers Internet
  • Administration à distance en SSH
  • Sécurité de niveau 2 et ACL inter-VLAN

02

Architecture

R1-ISP simule Internet et fournit la connectivité externe à R2-HQ. Sur le siège, R2-HQ gère le routage OSPF, le NAT/PAT, les ACL et l'accès SSH, et relie SW1-CORE en trunk 802.1Q.

  • SW1-CORE ↔ SW2 : EtherChannel LACP (Po1)
  • SW1-CORE ↔ SW3-ACCESS : trunk, 3 VLAN distribués aux postes (10 ADMIN, 20 USERS, 30 SERVERS)
  • R2-HQ ↔ R3-BRANCH : liaison WAN routée en OSPF
  • R3-BRANCH gère le DHCP de l'agence et relie SW4 avec 2 VLAN (110 SALES, 120 GUEST)

05

VLAN & Trunks

Création des VLAN sur SW1 et SW3, affectation des ports d'accès et mise en trunk du lien vers le cœur de réseau. 

vlan 10
 name ADMIN
vlan 20
 name USERS
vlan 30
 name SERVERS

! SW3 - ports d'accès
interface fa0/2
 switchport mode access
 switchport access vlan 10
interface fa0/3
 switchport mode access
 switchport access vlan 20
interface fa0/4
 switchport mode access
 switchport access vlan 30

! Trunk vers SW1
interface fa0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30

Vérification : show vlan brief et show interfaces trunk

06

EtherChannel LACP

Agrégation de deux liens entre SW1 et SW2 pour doubler la bande passante et apporter de la redondance. 

interface range fa0/23 - 24
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30
 channel-group 1 mode active

interface port-channel 1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30

Vérification avec show etherchannel summary : Po1(SU) en LACP, avec Fa0/23(P) et Fa0/24(P) correctement intégrés.

07

Routage inter-VLAN & OSPF

Router-on-a-Stick (R2)

interface gigabitEthernet 0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0

interface gigabitEthernet 0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0

interface gigabitEthernet 0/0.30
 encapsulation dot1Q 30
 ip address 192.168.30.1 255.255.255.0

OSPF entre R2-HQ et R3-BRANCH

! R2-HQ
router ospf 1
 router-id 1.1.1.1
 network 10.0.0.4 0.0.0.3 area 0
 network 192.168.10.0 0.0.0.255 area 0
 network 192.168.20.0 0.0.0.255 area 0
 network 192.168.30.0 0.0.0.255 area 0

! R3-BRANCH
router ospf 1
 router-id 3.3.3.3
 network 10.0.0.4 0.0.0.3 area 0
 network 192.168.110.0 0.0.0.255 area 0
 network 192.168.120.0 0.0.0.255 area 0

Vérification : show ip ospf neighbor doit indiquer l'état FULL.

08

DHCP

Service DHCP configuré sur R3 pour les postes de l'agence.

ip dhcp excluded-address 192.168.110.1 192.168.110.9
ip dhcp pool VLAN110-SALES

 default-router 192.168.110.1

ip dhcp excluded-address 192.168.120.1 192.168.120.9

09

Sécurité de niveau 2

Port Security

Un seul MAC autorisé par port utilisateur, apprentissage automatique (sticky) et restriction en cas de violation. 

interface range fa0/2 - 4
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address sticky
 switchport port-security violation restrict
 spanning-tree portfast
 spanning-tree bpduguard enable

DHCP Snooping & Dynamic ARP Inspection

Protection contre les serveurs DHCP non autorisés et l'usurpation ARP sur SW3. 

ip dhcp snooping
ip dhcp snooping vlan 10,20,30
ip arp inspection vlan 10,20

interface fa0/1
 ip dhcp snooping trust
 ip arp inspection trust

interface range fa0/2 - 4
 ip dhcp snooping limit rate 10
 ip arp inspection limit rate 15

Administration SSH

hostname R2-HQ
ip domain-name entreprise.local
username admin privilege 15 secret Admin@2026!
crypto key generate rsa
ip ssh version 2

line vty 0 4
 login local
 transport input ssh

Vérification : show port-security, show ip dhcp snooping, show ip arp inspection, show ip ssh

10

ACL inter-VLAN

Les utilisateurs (VLAN 20) n'ont pas accès au VLAN ADMIN, mais peuvent joindre les serveurs et l'agence. 

ip access-list extended USERS-POLICY
 deny ip 192.168.20.0 0.0.0.255 192.168.10.0 0.0.0.255
 permit ip 192.168.20.0 0.0.0.255 192.168.30.0 0.0.0.255
 permit ip 192.168.20.0 0.0.0.255 192.168.110.0 0.0.0.255
 permit ip 192.168.20.0 0.0.0.255 192.168.120.0 0.0.0.255
 permit ip any any

Le VLAN GUEST (120) est quant à lui totalement cloisonné : aucun accès aux autres réseaux internes. 

ip access-list extended GUEST-POLICY
 deny ip 192.168.120.0 0.0.0.255 192.168.10.0 0.0.0.255
 deny ip 192.168.120.0 0.0.0.255 192.168.20.0 0.0.0.255
 deny ip 192.168.120.0 0.0.0.255 192.168.30.0 0.0.0.255
 deny ip 192.168.120.0 0.0.0.255 192.168.110.0 0.0.0.255
 permit ip any any

Vérification : show access-lists

11

NAT / PAT

Traduction des adresses privées du siège vers Internet via PAT (surcharge sur l'interface WAN). 

interface gigabitEthernet 0/0.10
 ip nat inside
interface gigabitEthernet 0/0.20
 ip nat inside
interface gigabitEthernet 0/0.30
 ip nat inside
interface gigabitEthernet 0/1
 ip nat outside

ip access-list standard NAT-HQ
 permit 192.168.10.0 0.0.0.255
 permit 192.168.20.0 0.0.0.255
 permit 192.168.30.0 0.0.0.255

ip nat inside source list NAT-HQ interface gigabitEthernet 0/1 overload
ip route 0.0.0.0 0.0.0.0 10.0.0.1

Vérification : show ip nat translations après un ping depuis un poste vers 8.8.8.8.

13

Limites & bilan

Un tunnel VPN IPsec site-à-site entre R2-HQ et R3-BRANCH était prévu, mais la version de Packet Tracer utilisée ne supporte pas correctement les commandes IPsec/IKE nécessaires. Ce point est documenté comme une limite de l'environnement de simulation, avec une v2 envisagée sous GNS3 ou EVE-NG.

J'ai conçu une infrastructure Cisco multi-site avec segmentation VLAN, routage inter-VLAN, EtherChannel LACP et OSPF entre un siège et une agence, puis sécurisé l'ensemble avec Port Security, DHCP Snooping, Dynamic ARP Inspection, SSH et des ACL inter-VLAN — en validant chaque fonctionnalité avec les commandes de troubleshooting Cisco.
