Cybersécurité

Analyse forensique

Investigation numérique d'un poste informatique à l'aide du logiciel open-source Autopsy.

Autopsy Forensique Windows Investigation

01

Contexte

Une entreprise souhaitait examiner le poste informatique d'un collaborateur soupçonné d'avoir effectué des actions suspectes sur le matériel et les données de l'entreprise.

L'objectif était de rechercher des traces d'activités inhabituelles tout en conservant l'intégrité des éléments analysés.

02

Objectifs

  • Identifier d'éventuelles connexions à distance.
  • Rechercher des copies non autorisées de documents.
  • Examiner les traces de navigation web.
  • Identifier les fichiers supprimés ou récemment utilisés.
  • Collecter et préserver les éléments utiles à l'investigation.

03

Analyse avec Autopsy

Le disque dur a d'abord été cloné afin de travailler sur une copie de la machine sans modifier le support original.

Le clone a ensuite été transformé en machine virtuelle puis analysé avec Autopsy.

Modules utilisés

File Type Identification Identification des types de fichiers
Keyword Search Recherche de mots-clés
Web Artifacts Analyse des traces de navigation
Web Cookies Parser Analyse des cookies
Windows Event Log Parser Analyse des journaux Windows
Recent Documents Analyse des documents récents
Windows Registry Analyzer Analyse du registre Windows

04

Résultats

L'analyse de l'historique Firefox a montré que les données disponibles ne remontaient qu'au 21/02/2024, ce qui constituait un élément notable dans l'investigation.

Plusieurs traces de fichiers et de raccourcis anciens ont également été retrouvées.

Aucun logiciel de prise en main à distance suspect n'a été identifié sur le poste.

Un partage réseau accessible à tous a toutefois été identifié puis désactivé afin de préserver la confidentialité des données.
