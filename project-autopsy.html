03 / PROJET

Analyse forensique avec Autopsy

Investigation d'un poste informatique afin d'identifier d'éventuelles activités suspectes et de préserver les éléments pouvant constituer des preuves numériques.

Autopsy Forensics Cybersécurité Windows

01

Contexte

Une entreprise souhaitait examiner le poste informatique d'un collaborateur à la suite de comportements considérés comme suspects.

L'objectif était d'identifier d'éventuelles connexions distantes, des copies non autorisées de documents ou encore des traces de navigation problématiques, tout en conservant l'intégrité des éléments analysés.

02

Préservation

Afin de ne pas travailler directement sur le poste original, une copie du disque a été réalisée à l'aide d'Acronis.

Le clone obtenu a ensuite été transformé en machine virtuelle afin de pouvoir effectuer l'analyse dans un environnement contrôlé.

La préservation de l'intégrité et de la confidentialité des données était une priorité durant toute l'investigation.

03

Investigation

L'analyse a été réalisée avec Autopsy, solution open source dédiée à l'analyse forensique de supports numériques.

Modules utilisés

File Type Identification Identification des types de fichiers.
Keyword Search Recherche de mots-clés dans les données.
Web Artifacts Analyse des traces de navigation.
Web Cookies Parser Analyse des cookies et interactions web.
Windows Event Log Parser Analyse des journaux Windows.
Recent Documents Identification des documents récemment utilisés.
Windows Registry Analyzer Analyse du registre Windows.

04

Résultats

Plusieurs éléments ont été observés au cours de l'investigation.

  • Aucune trace de logiciel de prise en main à distance.
  • Le Bureau à distance Windows était désactivé.
  • Un partage réseau « Users » accessible à tous a été identifié.
  • Le partage « Users » a été désactivé afin de préserver la confidentialité.
  • L'historique Firefox ne remontait qu'au 21/02/2024.
  • Des traces de fichiers et dossiers anciens ont été retrouvées.
  • Aucun logiciel compromettant n'a été identifié.

05

Bilan

Cette investigation m'a permis de découvrir concrètement les méthodes utilisées dans une analyse forensique et l'importance de travailler sur une copie afin de préserver les données originales.

J'ai également développé mes compétences en analyse de systèmes Windows, en recherche de traces numériques et en documentation des résultats.
